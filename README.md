# Seat Booking System

A menu-driven Java console application that manages seat bookings using an `ArrayList`.

## Features
- Book a new seat (rejects duplicates)
- Cancel a booking (soft delete using a `canceled` flag)
- Update a booking to a different seat
- Display all active bookings with booking dates

## Concepts practiced
- `ArrayList` operations (`add`, `get`, `size`, iteration)
- Object-oriented design (`Seat` model, `SeatBooking` controller, `Main` menu)
- String comparison with `.equals()` instead of `==`
- Input handling with `Scanner`

## How to run
1. Clone the repo
2. Open it in IntelliJ IDEA (JDK 21)
3. Run `Main.java`

## Sample menu
1. Add Booking
2. Cancel Booking
3. Update Booking
4. Display Bookings
5. Exit
